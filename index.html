Publikacja i dane

Streamlit Cloud (automatyczne dane GUNB) lub GitHub Pages (import ręczny)

1. Streamlit Community Cloud — dane pobierane automatycznie

  1. W repozytorium GitHub umieść: index.html, app.py, gunb_loader.py, requirements.txt (wpis: streamlit).
  2. Na share.streamlit.io wybierz repozytorium i plik app.py → Deploy.
  3. Serwer co 6 godzin pobiera z GUNB plik województwa (domyślnie mazowieckie) i odrzuca domy, sieci i stare sprawy. Inne województwo: dopisz do adresu ?region=slaskie (albo wielkopolskie, lodzkie, malopolskie…), dłuższy okres: &dni=730.

2. GitHub Pages — sam index.html

Strona działa bez serwera, ale dane trzeba wczytać ręcznie: Dane / Import → upuść ZIP z GUNB. Import zostaje zapamiętany w przeglądarce.

3. Ograniczenia danych RWDZ

  • Urzędy wpisują dane z opóźnieniem i z błędami (zła kategoria, kubatura 0) — dlatego Smart Match patrzy też na nazwę zamierzenia.
  • Wyszukiwarka GUNB wymaga kodu z obrazka (10 stron na kod), więc aplikacja korzysta z plików „Dane do pobrania”; przyciski „Pokaż w GUNB” otwierają gotowe wyszukiwanie do weryfikacji.
  • Duże inwestycje bywają u Wojewody, a nie u Starosty — wtedy powiat ustalany jest z kodu TERC / działki.
  • Działki lokalizujemy po identyfikatorze w ULDK GUGiK; gdy numer jest nieaktualny (podział), sprawa zostaje w tabeli bez kształtu na mapie.
