Publikacja: GitHub Pages & Streamlit Cloud

Udostępnianie aplikacji linkiem i pobieranie danych GUNB

1. Uruchomienie na Streamlit Community Cloud (z GitHuba)

  1. Utwórz repozytorium na GitHubie i wrzuć plik index.html oraz dwa krótkie pliki: app.py i requirements.txt (z wpisem streamlit).
  2. W pliku app.py wczytaj index.html za pomocą streamlit.components.v1.html(..., height=900).
  3. Wejdź na share.streamlit.io, zaloguj się przez GitHub, kliknij Create app, wybierz swoje repozytorium, gałąź main i plik app.py, a następnie kliknij Deploy.

2. Alternatywa: GitHub Pages (sam plik index.html, bez Pythona)

  1. Wgraj index.html do repozytorium na GitHubie.
  2. Wejdź w Settings → Pages, wybierz gałąź main i folder / (root), kliknij Save.
  3. Aplikacja uruchomi się pod adresem https://twoj-login.github.io/nazwa-repo/.

3. Pobieranie aktualnych wniosków CSV z GUNB (RWDZ)

  1. Wejdź na wyszukiwarka.gunb.gov.pl lub dane.gov.pl (zbiór RWDZ — wnioski).
  2. Kliknij Import CSV w HalaRadar i upuść plik — aplikacja automatycznie dociągnie rzeczywiste kształty działek z ULDK GUGiK.
